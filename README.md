# SNUBH AI Cookbook

> Validated prompts, workflows, and evaluation protocols for clinical AI translation.
> Maintained by [SNUBH Vibe Lab](https://github.com/snubh-vibe-lab).

## Status

🚧 Under construction — initial public release planned for September 2026.

## Structure

- `prompts/` — clinical-task-specific prompts validated in production workflows
- `workflows/` — multi-step agentic workflows (Claude Code, MCP)
- `tools/` — small tools and scripts built by lab members
- `case-studies/` — write-ups of real clinical applications
- `evaluations/` — evaluation protocols for clinical AI outputs
